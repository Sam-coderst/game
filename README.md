# 刹不住的清洁工（Slippery Cleaner） v0.2

无需构建、无外部资源的原生 Canvas 游戏，包含单人挑战、同键盘双人对抗、首次操作引导和本机排行榜。

## 启动

在项目文件夹中运行（保持终端窗口开启）：

```powershell
python -m http.server 8000
```

浏览器访问 http://localhost:8000/ 。如果找不到 python，可用 `py -m http.server 8000`。也可在文件管理器中双击 `index.html`。加载旧界面时按 Ctrl+F5。不要同时开启多个占用 8000 端口的服务器。

文件方式、localhost、127.0.0.1 和不同端口可能使用不同的浏览器存储空间；要沿用排行榜，请使用同一个地址和浏览器。

## 主页与新手引导

- 主页提供昵称、单人挑战、双人对抗、新手练习、本机排行榜和单人最高纪录。
- 昵称可留空，默认“清洁工 1 / 清洁工 2”；最多 12 个字符，纯文本显示。
- 第一次选择任意模式会进入不计时练习：移动至标记 → 吸入 3 件垃圾 → 自动补为 16 件，练习重载刹车并回收。
- 完成或跳过后记住引导状态，可在主页随时重练。练习成绩不入榜，开始正式局时全部重置。
- 首次选择双人时，练习结束后进入双人准备界面；双方点击就绪后才开始计时。

## 操作与规则

| 模式 | P1 | P2 | 卸货规则 |
| --- | --- | --- | --- |
| 单人 | WASD / 方向键 / 屏幕方向键 | — | 绿色回收站 |
| 双人 | WASD，绿色机器人 | 方向键，蓝色机器人 | 只能在各自颜色的回收站卸货 |

- 每局 90 秒，只计算已卸货的得分；双人分数相同为平局。
- 碰到垃圾自动吸入；最大载重 20。1–5 件 ×1、6–10 件 ×1.2、11–15 件 ×1.5、16–20 件 ×2；每件基础分 10，整批取整。
- 载重越大，惯性越强；反向输入可主动制动。高速撞家具掉落少量垃圾，低速不处罚，掉落物有短暂拾取冷却。
- 双人使用左右对称家具、出生位置和成对生成的垃圾。两人争抢同一批资源，按距离决定拾取归属，同距按垃圾编号轮换优先；不会重复计入两人背包。
- 两台机器人可交错通过，不互相推挤或撞掉货；家具撞击掉落的垃圾冷却后双方均可捡走。
- P / Esc 或暂停按钮暂停；失焦或切换标签自动暂停并清空双方按键，返回后需手动继续。
- 暂停页可结束本局回主页，未完成对局不会入榜。结算页支持再来一局、查看排行榜和返回主页。
- 手机单人提供多指方向键；竖屏旋转房间，屏幕方向与输入保持一致，回收站文字和浮字保持正向。双人模式需要实体键盘。

## 本机排行榜

- 通过 localStorage 保存，不联网、不上传、不跨设备同步；清除浏览器数据会丢失。
- 单人榜：完整对局的个人得分前 10 名，同一昵称可多次出现。
- 双人榜：完整对抗场次前 10 名，按本场最高个人分排序，展示双方昵称、比分及胜者/平局。
- 同分按对局时间先后排列；每局只记录一次。练习、中途退出不会计入。
- 保留旧版单人最高分用于主页展示，不伪造历史对局填入排行榜。
- 存储损坏或被禁用时仍能玩；写入失败会提示纪录仅在当前页面临时保留。

## 文件与参数

- `index.html`：主页、引导提示、游戏 HUD、对抗准备、暂停/结算、排行榜。
- `styles.css`：本地 CSS 插画、主页视觉和桌面/手机布局。
- `core.js`：速度、加速度、阻尼、载重、计分、碰撞阈值和垃圾数量参数。
- `game.js`：状态切换、双人输入、移动/碰撞、教程、地图、生成、渲染与音效。
- `profile.js`：昵称、引导标记、榜单验证/排序/持久化及存储失败降级。
- `tests.js`：核心规则和持久化测试。
- `integration-tests.js`：用 DOM 替身执行真实游戏代码的流程回归；不属于浏览器试玩。
- `browser-smoke.js`：可选本机浏览器冒烟脚本，本轮未执行成功，不能当作已通过的证据。

单人自然补充上限 22、场内硬上限 42；双人自然补充上限 30、硬上限 70，为两台满载机器人的掉货预留容量。粒子、浮字、尾迹均有上限。平台相关行为集中于无副作用的 `Platform` 适配层。URL 添加 `?debug` 仅显示调试速度与碰撞圆。

## 下一步人工试玩

### 场景与界面更新

主页新增客厅巡游、卧室绕行、厨房穿梭三种任务选择。卧室的床与衣柜、厨房的灶台与岛台均有独立碰撞布局和配色，两种模式都支持；新手练习固定使用客厅，完成后回到选定场景。新场景双人布局左右对称。排行榜目前仍按单人/双人汇总所有场景，属于综合榜，不是分场景纪录。

界面增加街机外框、立体按钮、场景选择卡及最后 10 秒高亮。程序测试已覆盖三个场景在两种模式下的出生点、垃圾落点及可行走网格连通性；尚未完成新版视觉和真人手感验收。

1. 重新打开主页：首次模式选择是否进入引导，三步能否自然完成，跳过后是否进入正确模式。
2. 两人同时按键并斜向移动：键盘是否能识别组合，回错站不计分，结算双方分数是否清楚。
3. 完整玩一局，查看榜单并刷新，确认昵称和分数保留；再从双人切回单人。
4. 手机横竖屏下的面板可见性、触控松手、声音恢复、满载制动与家具边角。

部分实体键盘可能限制同时识别的按键数量，需在目标设备上实测。排行榜是本机休闲记录，不具备联网比赛的防篡改能力。
